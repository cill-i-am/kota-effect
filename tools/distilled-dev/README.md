# Vendored distilled code generator

This directory is an unmodified copy of `packages/dev/src` from
[alchemy-run/distilled](https://github.com/alchemy-run/distilled), commit
`88e9b65aa57471b0870eb18f30029261f5b70a05` (2026-11-12, `v1.0.0-rc.19`).
The only removal is `src/testing.ts`, a vitest helper the generator does not use.

distilled publishes its runtime (`@distilled.cloud/core`) to npm, but keeps the
generator private to its monorepo. It is vendored here so `@kota/effect` is
generated by the same OpenAPI → Smithy → TypeScript pipeline as every distilled
SDK, and its output runs on the published `@distilled.cloud/core`.

## Updating

```sh
pnpm vendor:distilled <commit-or-branch>   # re-copies packages/dev/src at that ref
pnpm generate                              # regenerate the SDK with it
```

Bump `@distilled.cloud/core` in `packages/kota/package.json` to the release
that matches the vendored commit.
